## ဘာကြောင့် ဒီ Repository ကို ဖန်တီးဖြစ်တာလဲ (Why I Built This)

ကျွန်တော့်အလှည့်တုန်းက Honda Y-E-S Award ကို လျှောက်ဖို့ အတော်လေး ခက်ခဲခဲ့ပါတယ်။ ဘယ်ကစပြီး ဘာကိုပြင်ဆင်ရမလဲ၊ အက်ဆေးကို ဘယ်လိုရှုထောင့်ကနေ ရေးရမလဲ၊ အင်တာဗျူးမှာ ဘာတွေအဓိကကြည့်လဲဆိုတာ တိတိကျကျ စုစည်းထားတဲ့ လမ်းညွှန်မျိုး မရှိခဲ့ပါဘူး။

အဲ့ဒီလို လမ်းစရှာမရဘဲ စမ်းတဝါးဝါးနဲ့ ဖြတ်သန်းခဲ့ရတာကြောင့် **5th Year မှာ တစ်ကြိမ်၊ Final Year မှာ တစ်ကြိမ် စုစုပေါင်း (၂) နှစ်တိတိ** ဖြေဆိုကြိုးစားပြီးမှ 2025 Honda Y-E-S Award ကို ရရှိခဲ့တာပါ။

နောက်လာမယ့် ဂျူနီယာတွေကိုတော့ ကျွန်တော်ကြုံခဲ့ရသလို ဘယ်ကစရမှန်းမသိဖြစ်ပြီး မလိုအပ်ဘဲ အချိန်ကုန်၊ ဒုက္ခမရောက်စေချင်ပါဘူး။ ကိုယ်တွေ့ဖြတ်သန်းခဲ့တဲ့ အတွေ့အကြုံတွေနဲ့ လက်တွေ့အသုံးဝင်တဲ့ နည်းဗျူဟာတွေကို တစ်နေရာတည်းမှာ စနစ်တကျ စုစည်းပြီး အခမဲ့ မျှဝေပေးထားတာ ဖြစ်ပါတယ်။

## Web Portal ရဲ့ အဓိက Feature များ

* **Interactive Markdown Reader:** `.md` ဖိုင်များကို Browser ပေါ်တွင် Sticky Table of Contents (မာတိကာ) နှင့်တကွ တိုက်ရိုက်ဖတ်ရှုနိုင်ခြင်းနှင့် `.md` မူရင်းဖိုင် Download ရယူနိုင်ခြင်း။
* **Dynamic Read-Time Calculator:** စာတမ်းတစ်စောင်ချင်းစီ၏ ဖတ်ရှုချိန်ကို အလိုအလျောက် တွက်ချက်ပြသပေးခြင်း။
* **Selection Benchmark & Rubric Dashboard:** 2021 Direct-to-MAJA Funnel Data (`183 → 40 → 15 → 10 → 4`) ကို Chart.js ဖြင့် ဖော်ပြထားပြီး Essay အမှတ်ပေးစံနှုန်းနှင့် Interview English ဦးစားပေးအစဉ်ကို တစ်ချက်တည်း ကြည့်နိုင်ခြင်း။
* **Synced Dark / Light Mode:** Honda Foundation Heritage Theme (Warm Cream & Gold / Warm Charcoal Dark Mode) ပါဝင်ပြီး MEXT Portal နှင့် Theme Setting အလိုအလျောက် ချိတ်ဆက်ထားခြင်း။
* **Community Q&A Forum:** GitHub Discussions (Giscus) မှတစ်ဆင့် မေးခွန်းများ တိုက်ရိုက်မေးမြန်း ဆွေးနွေးနိုင်ခြင်း။

## Local တွင် စမ်းသပ်အသုံးပြုနည်း (Running Locally)

ဒီ Project က Static Website (HTML, CSS, Vanilla JS + CDN libraries) ဖြစ်တဲ့အတွက် Build step မလိုပါဘူး။ ဒါပေမဲ့ Markdown ဖိုင်တွေကို `fetch()` နဲ့ ခေါ်ဖတ်ထားတာဖြစ်လို့ `index.html` ကို `file:///` နဲ့ တိုက်ရိုက်ဖွင့်ရင် Browser ရဲ့ CORS Policy ကြောင့် စာတမ်းတွေ ပွင့်မှာမဟုတ်ပါဘူး။ Local server တစ်ခုခုနဲ့ ဖွင့်ကြည့်ပါ—

```bash
# 1. Repository ကို Clone လုပ်ပါ
git clone [https://github.com/robinglory/myanmar-honda-yes-award-roadmap.git](https://github.com/robinglory/myanmar-honda-yes-award-roadmap.git)
cd myanmar-honda-yes-award-roadmap

# 2. Python ဖြင့် Local Server ဖွင့်ပါ (သို့မဟုတ် VS Code Live Server ကို သုံးပါ)
python -m http.server 8000

```

ပြီးရင် Browser မှာ `http://localhost:8000` ကို ဖွင့်ကြည့်လို့ ရပါပြီ။
